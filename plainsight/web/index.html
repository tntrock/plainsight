    HTTPS 解密實驗：為什麼不能亂裝憑證

    HTTPS 能防止被竊聽，前提是你的裝置只信任正當的憑證機構。 一旦裝置被誘導安裝了攻擊者的根憑證（例如「免費 Wi-Fi 請安裝此描述檔」），中間人就能解密所有 HTTPS。 以下步驟讓你在自己的實驗裝置上重現這件事：

    1. 安裝 mitmproxy：pip install mitmproxy
    2. 啟動儀表板：plainsight mitm（其他模式也會接收）
    3. 另開終端機執行：mitmdump -s mitm_addon.py --listen-port 8080
    4. 把實驗裝置的 HTTP 代理設為「這台電腦的 IP:8080」
    5. 在實驗裝置開啟 http://mitm.it，安裝並信任憑證
    6. 瀏覽任何 HTTPS 網站、用測試帳號登入 → 儀表板出現 MITM 解密
    7. 實驗結束後，務必從裝置移除該憑證！

    提示：有實作 Certificate Pinning 的 App（多數銀行 App）會拒絕連線，這正是正確的防護。
